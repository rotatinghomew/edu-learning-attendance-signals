# 课程构成变化下的出勤异常证据与处置排序

面向社区老年教育运营的本地分析原型：把**课程监测、异常解释和有限的联系能力**接成一条
可重放、可审计的流水线。所有记录均为本地合成数据，不包含真实个人信息；纯 Python 标准库
实现，无第三方依赖。

## 环境与使用

需要 Python 3.11 或更高版本。

```bash
python3 -m unittest discover -s tests -v          # 47 个测试
python3 -m learning_attendance_signals.report     # 合成数据端到端演示（内存+SQLite 对账）
```

Docker：

```bash
docker build -t learning-attendance-signals .
docker run --rm learning-attendance-signals
docker run --rm --entrypoint python3 learning-attendance-signals -m unittest discover -s tests -v
```

SQLite 数据库在调用时创建于临时目录，原始 CSV/原始出勤记录保持不变。

## 业务口径与模块结构

| 模块 | 职责 |
|---|---|
| `models.py` | 课程、学员、在册资格、课表、出勤、问题状态机等领域模型 |
| `synthetic.py` | 确定性合成数据集，覆盖下方全部业务场景 |
| `calendar.py` | 出勤事实口径：应到义务、在册资格、原始账隔离 |
| `monitoring.py` | 自有基线、二项下尾检验、BH 多重比较校正、持续性确认、证据分级 |
| `decomposition.py` | 总体率变化拆成同类内部效应 / 构成效应 / 新开课效应 |
| `explanations.py` | 人工说明（仅当轮有效）与权威改课记录（改变可比基线）两条路径 |
| `operations.py` | 联系预算、跨班学员去重、证据×覆盖排序、处置状态迁移 |
| `audit.py` / `storage.py` | 审计事件流；内存与 SQLite 两套同接口仓储 |
| `pipeline.py` / `report.py` | 逐轮编排与演示输出 |
| `legacy.py` | 早期通用 CSV 汇总流程的兼容层（`records/analysis/operations.review`） |

### 监测尊重"实际应到"

- 调课日（`RESCHEDULED_OUT`）不产生应到义务，**没有到场记录不等于缺席**；补课
  （`MAKEUP`）与正常课同口径；停课轮没有率、监测挂起。
- 分母只含课次当日处于在册有效期内的学员；无在册资格、重复提交的原始记录进入
  **隔离区**并写审计，绝不静默丢弃或悄悄修正。
- 每门课只与**自己的、同 cohort 的、非停课且未被标记的稳定历史**比较；新开课缺少
  自有历史时只观察、不确认，绝不借用其他课程的稳定程度。

### 异常不等于单点波动

- 单轮用二项分布下尾概率检验（小样本精确、大样本正态近似），同一轮观察多门课程时用
  Benjamini-Hochberg 控制错误发现率，孤立的"边缘显著"波动不会升级。
- 信号需连续 2 轮确认才成为待联系问题；单轮波动后自行恢复只留在观察中。
- 证据按降幅、调整后 p 值与受影响人数分为强/中/弱，并始终给出受影响学员集合。
- 总体率变化被分解为**同类内部效应、构成效应、交互项、新开课贡献**：新开热门课抬高
  总量时，老课程的内部恶化仍单独可见且可报警。

### 解释不能冒充事实

- 人工说明精确绑定（课程, 轮次），只抑制该轮升级；**下一轮真实下降必须重新检验**，
  旧说明不能当免责；被抑制轮不进入基线。
- 权威改课/停课是课表事实：停课轮监测挂起并从基线排除，恢复后用停课前后的自有历史
  重建可比基线。
- 原始出勤账只增不改（重复写入被拒绝）；派生事实、信号、联系与审计分表存放并标注
  `basis`，校正后的数值不会伪装成真实人次。

### 有限联系能力与可追查性

- 每轮联系班级数受预算约束，排序分 = 证据权重 + 唯一覆盖奖励 + 持续性/无改善加成。
- 一个学员跨班报名时只被第一份包含他的联系占用预算；全流程联系名单不重复。
- 待联系、持续未联系、已解释停课、已联系、联系后无改善、已恢复是彼此独立的状态，
  联系后证据仍恶化会保留"联系后无改善"升级标记。
- 审计流回答三类问题：提醒**为什么出现/未出现**（未报警课程同样记录原因）、**为什么
  排在当前批次**（含分数拆解与去重人数）、**后续证据为何改变处置理由**（状态迁移留痕）。

## 合成数据场景地图（R1–R6）

| 课程 | 场景 | 预期行为 |
|---|---|---|
| C1 书法入门 | R3 起持续恶化的老课程 | R3 观察 → R4 确认并联系 → R5/R6 联系后无改善；基线锚定恶化前 0.90 |
| C2 声乐提高 | R4 单轮波动后恢复 | 永不升级为确定问题 |
| C3 太极班 | R4 调课+补课、R5 停课、R6 恢复 | 调课日不算缺席；停课挂起；恢复后基线来自停课前后稳定历史 |
| C4 智能生活 | R3 新开的高出勤热门课 | 新开课观察、不套用他人稳定性；其总量贡献在分解中单列 |
| C5 手工班 | R5 下降+人工说明，R6 再次下降 | R5 抑制、R6 旧说明不免责并重新报警 |
| C6–C9 | 稳定对照 | 不产生报警 |
| C10 摄影外拍 | R5/R6 连续恶化，8 名学员与 C1 重叠 | 跨班学员不重复占用联系预算 |

派生摘要只反映样例记录，不用于形成个体资格或运营承诺。
